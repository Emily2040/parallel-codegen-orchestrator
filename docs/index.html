6-Phase Workflow

  • Discovery: Extract acceptance criteria and constraints.
  • Plan: Build module boundaries and dependency waves.
  • Execute: Implement against frozen interfaces.
  • Recover: Resume from stable file/symbol anchors.
  • Verify: Run checks and report real evidence only.
  • Handoff: Deliver exact status, risks, and next commands.
